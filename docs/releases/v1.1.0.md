## MusicDecode 1.1.0

### English

- First cross-platform release: Windows x64, macOS Apple Silicon (ARM64), and Linux x64. Intel Macs are not supported.
- Simple neumorphic desktop interface with drag-and-drop, batch conversion, progress, cancellation, and a viewport-sized layout.
- Restore original MP3 audio without re-encoding; transcode FLAC, M4A, WAV and Ogg to MP3 at 192 / 256 / 320 kbps.
- Preserve embedded song metadata and artwork. Source files remain unchanged; existing outputs are never overwritten.
- Audio sidecar built from SHA-256-pinned FFmpeg 9.0.2 and LAME 3.100 source, with networking, GPL and nonfree components disabled.
- Three-platform conversion regression tests use generated audio. Personal music files are not part of this repository or CI.

**Downloads:** Windows: `*-setup.exe`; macOS ARM64: `*.dmg`; Linux x64: `*.AppImage` or `*.deb`. Verify files against the matching `SHA256SUMS-*.txt`.

**Signing:** Windows installers are not code-signed. The macOS app uses an ad-hoc signature and is not Apple-notarized; Gatekeeper may require approval through System Settings → Privacy & Security. These installers are distributed directly, not through an app store. Linux AppImage users should run `chmod +x` on the downloaded file.

The release also includes the complete corresponding audio source archives, checksums and build script. See the bilingual README for installation and development instructions. The application UI is currently in Simplified Chinese.

### 中文

- 首个三端版本：Windows x64、macOS Apple Silicon（ARM64）、Linux x64；不提供 Intel Mac 版本。
- 简约新拟态界面，支持拖拽、批量转换、进度与取消；整个窗口不滚动，仅歌曲列表独立滚动。
- 内部为 MP3 时直接还原，不重新压缩；其他支持格式可转为 192 / 256 / 320 kbps MP3。
- 保留内嵌歌曲信息和封面，源文件始终保留，同名输出自动编号。
- 从固定源码编译 FFmpeg 9.0.2 + LAME 3.100 精简音频组件，校验源码 SHA-256；禁用网络、GPL 和 nonfree 组件。
- 三端自动回归测试使用生成音频，仓库和 CI 不包含个人歌曲文件。

**下载选择：** Windows 选择 `*-setup.exe`；Apple Silicon Mac 选择 `.dmg`；Linux x64 选择 `.AppImage` 或 `.deb`。可使用对应的 `SHA256SUMS-*.txt` 校验文件。

**签名情况：** Windows 安装包未做代码签名；macOS 使用临时签名，未做 Apple 公证，可能需要通过“系统设置 → 隐私与安全性”批准打开。安装包通过本仓库直接分发。Linux AppImage 下载后需要赋予执行权限。

本次发布同时提供音频组件的完整对应源码、校验清单和构建脚本。安装和开发步骤见中英文 README。软件界面目前为简体中文。
